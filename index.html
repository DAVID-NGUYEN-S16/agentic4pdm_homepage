The framework

Freedom to investigate.
Discipline in evidence use.

LLM agents identify the questions that remain unresolved. Contract-checked gated adjudication (CCGA) controls which measurements may run, how results may support a class, and whether the proposed diagnosis is admitted.

01

Request gate

Declare unresolved signal properties, receive compatible tools, commit to a complete batch, and execute. The host checks coverage and prevents revisiting measured properties.

Declare → Offer → Commit → Execute
02

Packet & influence gate

Test each tool on known-label controls. Usable results become corroborative if every control is recovered, or advisory otherwise. Failed or ambiguous packets are excluded.

Checked support or advisory information
03

Finalization

Admit a proposal only if its class is in the initial candidate set and a quantitative measurement round is complete. Otherwise, return it for revision within the step budget.

A class + its admission status

Standard mode

Pretrained embeddings and labeled references, plus SVM and XGBoost predictions as hypotheses to investigate. The main results use this mode.

Training-free mode

Pretrained representations and labeled references, with no task-specific fitted diagnostic classifier. Evaluated separately in the appendix.

Read the full abstract +
We study industrial fault diagnosis as a classification task that assigns sensor time-series windows to predefined health states or fault types. Scarce labels and changing operating conditions make repeated training of specialized classifiers costly. Yet structures such as periodicity, trends, and transients can remain diagnostically informative and be examined through reusable analytical tools. LLM agents can select and interpret these tools, but fixed rules or training-derived guidance may not resolve each signal’s ambiguity, while unconstrained interpretation may overstate weak or conflicting results. We introduce Agentic4PDM, a framework that separates adaptive investigation from control over evidence use. LLM agents compare each signal with labeled references from every candidate class, identify unresolved distinctions, and propose follow-up measurements. A deterministic software controller, called the host, enforces contract-checked gated adjudication (CCGA): it checks requests, requires commitment to a complete tool batch before results are observed, and assigns evidence roles based on tool checks against labeled references. These roles distinguish corroborative support from advisory information. The Judge Agent proposes a diagnosis, while the controller checks protocol compliance and records the investigation. Agentic4PDM supports training-free diagnosis using pretrained representations and labeled references without task-specific diagnostic models, and a standard setting that additionally investigates trained-model predictions. Experiments on selected bearing and motor diagnosis challenges and an unfiltered industrial test set supplied by our customer show gains in aggregate macro F1 over the evaluated diagnostic and agentic baselines. Ablations further support the value of the governed workflow.

A closer look

What the investigation changes

Beyond aggregate scores, the paper examines prediction revisions, sample-specific plans, the contribution of evidence-handling controls, and whether simpler uses of the same evidence can match the workflow.

01 / Beyond fitted-model predictions

Agreement is a starting point

When SVM and XGBoost initially agree, Agentic4PDM can still correct their shared errors. On PU and MCC5 GRS, the consensus analysis reports a net accuracy gain of 7.97 percentage points, after accounting for new errors introduced.

Fitted-model predictions serve as hypotheses for further investigation.

02 / Sample-specific investigation

Different cases, different questions

Agentic4PDM produces 31 distinct plans on PU and 50 on MCC5, compared with one fixed plan for FETA and limited variation in ZARA.

Evidence acquisition varies with the case. This observation does not by itself show that plan diversity causes the performance gains.

04 / Simpler alternatives

Simple shortcuts do not reproduce the workflow

Could the same result come from voting over the evidence the Judge already has, or from one strong measurement? The paper tests both. Neither matches the full workflow.

Neither fixed aggregation of the initial evidence nor one strong measurement reproduces the full workflow. This is consistent with the value of choosing and combining measurements for the current case.
